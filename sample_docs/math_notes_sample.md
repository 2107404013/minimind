# Math Notes Sample

## Linear equations

To solve a one-variable linear equation, isolate the variable by applying the
same operation to both sides. For example, in `2x + 3 = 11`, subtract `3` from
both sides and then divide by `2`, giving `x = 4`.

## Rectangle area

The area of a rectangle is `length * width`. If the length is `8` and the width
is `5`, the area is `40`.
